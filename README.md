# ✦ 마법 적성 감정소 ✦

부스 방문 학생이 카메라(마법 거울) 앞에서 **손을 흔들어 마력을 모으면**
불 · 물 · 흙 · 공기 · 빛 중 하나의 속성이 무작위로 정해지고, 그 속성의 마법사로 감정해 주는 웹앱입니다.

바로 접속: **https://tnqssam.github.io/2026magic/**

- 손 인식: [MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker) (브라우저 안에서만 처리, 영상은 저장·전송하지 않음)
- 빌드 도구 없이 `index.html`, `style.css`, `app.js` 세 파일로 동작

## 실행 방법

카메라는 `https://` 또는 `localhost`에서만 켜지므로, 파일을 더블클릭하지 말고 로컬 서버로 여세요.

```bash
python3 -m http.server 8000
# 브라우저(Chrome 권장)에서 http://localhost:8000 접속
```

1. **감정소 열기** 버튼을 누르고 카메라 권한을 허용합니다. (전체화면으로 전환됩니다)
2. 학생이 손을 거울에 비추면 상태 표시가 초록색으로 바뀌고 마력 게이지가 차기 시작합니다.
   (가만히 있으면 약 3.5초, 손을 흔들면 더 빨리 찹니다. 손을 치우면 게이지가 줄어듭니다.)
3. 게이지가 가득 차면 마법진이 회전하며 속성이 정해집니다.
4. 결과 화면은 **화면을 클릭**(또는 Space)하면 처음 화면으로 돌아갑니다.

GitHub Pages에 올리면 `https://` 주소로 바로 사용할 수도 있습니다.

## 운영자 단축키

| 키 | 동작 |
| --- | --- |
| 클릭 | 결과 화면: 다음 사람으로 넘기기 |
| `Space` / `Enter` | 대기 화면: 바로 주문 시전 · 결과 화면: 다음 사람으로 넘기기 |
| `F` | 전체화면 켜기/끄기 |
| `M` | 효과음 켜기/끄기 |
| `Shift` + `R` | 오른쪽 아래 '탄생한 마법사' 통계 초기화 (오른쪽 아래 **초기화** 버튼으로도 가능) |

카메라가 없거나 손 인식이 안 될 때는 화면을 길게 누르고 있어도 게이지가 찹니다.

## 인터넷이 불안정한 부스라면 (오프라인 준비)

기본적으로 손 인식 라이브러리와 모델(약 20MB)을 인터넷(CDN)에서 받아옵니다.
미리 한 번 아래 스크립트를 실행해 두면 `vendor/` 폴더의 파일을 먼저 사용하므로 인터넷 없이도 동작합니다.
(글꼴만 인터넷이 없으면 기본 글꼴로 대체됩니다.)

```bash
./scripts/download-offline.sh
```

## 튜닝

`app.js` 상단의 값으로 조절할 수 있습니다.

- `CHARGE_MS` (기본 `3500`): 손을 가만히 보여줄 때 게이지가 가득 차는 시간(ms). 손을 흔들면 최대 약 2배 빨라집니다.
- `CAST_MS`: 게이지가 찬 뒤 속성을 고르는 연출 시간.
- `RESTART_GRACE_MS`: 결과 화면을 넘긴 직후 곧바로 다시 충전되지 않게 쉬는 시간.
- `ELEMENTS`: 속성별 이름·색·설명·특성·주문 문구.

## 팁

- 카메라 앞 1~2m, 손이 화면 안에 충분히 들어오도록 배치하세요. 역광(창문 등)은 피하는 게 좋습니다.
- 속성은 `crypto.getRandomValues`로 5개 중 균등한 확률(각 20%)로 뽑습니다.

# ✦ 원소 마법 · micro:bit ✦ (`microbit/`)

마이크로비트가 보내는 신호를 USB 시리얼(Web Serial)로 받아 **불 · 물 · 빛 · 공기 · 흙** 마법 효과를 화면에 펼치는 웹앱입니다.

바로 접속: **https://tnqssam.github.io/2026magic/microbit/** (Chrome 또는 Edge)

| 원소 | 효과 |
| --- | --- |
| 불 | 마법진에서 솟구치는 세 갈래 불기둥과 불티 |
| 물 | 나선 물줄기가 감아 올라 만드는 떠 있는 물의 구체, 물결과 물방울 |
| 빛 | 위에서 쏟아지는 빛줄기, 회전하는 꽃 모양 빛의 만다라와 빛나는 핵, 떠오르는 빛망울 |
| 공기 | 소용돌이치는 회오리바람, 바람 줄기와 날리는 나뭇잎 |
| 흙 | 땅을 뚫고 솟아오르는 바위 첨탑(빛나는 광맥), 퍼지는 균열과 흙먼지, 떠오르는 돌 조각 (화면 흔들림) |

### 마이크로비트 준비 (MakeCode)

1. **받는 마이크로비트**(컴퓨터에 USB 연결): `라디오 그룹 설정` → `라디오 수를 받았을 때` → `시리얼 한 줄 쓰기 (receivedNumber)`
   - 라디오 그룹 번호는 마법봉과 받는 마이크로비트가 **서로 같기만 하면 아무 숫자(0~255)** 나 됩니다. 웹앱은 그룹 번호와 상관없습니다.
   - 한 교실에서 여러 모둠이 동시에 하면 **모둠마다 다른 그룹 번호**를 써야 다른 모둠의 마법봉 신호가 섞이지 않습니다.
2. **원소는 웹앱 왼쪽 메뉴**(또는 숫자 키 `1`~`5`)로 고릅니다.
3. **마법봉 마이크로비트**는 같은 그룹에서 `라디오 수 보내기`로 아래 숫자를 보냅니다.

| 보낼 숫자 | 뜻 | 동작 |
| --- | --- | --- |
| `1` | SPELL | 화면에서 고른 원소 마법 펼치기. 1이 계속 오는 동안 유지되고, 3초 동안 1이 더 안 오면 저절로 꺼짐 |
| `2` | STOP | 멈추기: 원소마다 다른 마무리 연출 후 꺼짐 (아래 표) |
| `3` | NOTHING | 기본 상태로 돌아가기: 마법이 천천히 작아지며 바닥 마법진 속으로 가라앉고, 마법진이 닫히며 사라짐 (약 3초) |

멈추기(`2`)를 받으면 먼저 화면이 **0.45초 동안 얼어붙고**(움직임 정지·색 빠짐·번쩍임·충격파·흔들림), 이어서 원소마다 다른 마무리 연출이 약 2초 동안 나온 뒤 꺼집니다. 연출 중에 `3`이 와도 끝까지 보여 주고, 새 `1`이 오면 바로 다시 시전합니다.

| 원소 | 멈추기 연출 |
| --- | --- |
| 불 | 불길이 주저앉고 재가 되어 흩날리며, 연기만 남고 사라짐 |
| 물 | 물의 구체가 부풀었다 터져 물방울이 흩어지고, 바닥에 큰 물결이 퍼짐 |
| 빛 | 빛줄기와 만다라가 핵으로 빨려 들어간 뒤 번쩍이며 빛의 고리가 퍼지고 사라짐 |
| 공기 | 회오리가 넓게 풀리며 옅어지고, 나뭇잎이 팔랑이며 땅에 떨어짐 |
| 흙 | 바위 첨탑이 차례로 땅속으로 무너지고, 흔들림과 함께 흙먼지가 크게 일어남 |

마법 효과는 주문 동작(1)을 받을 때만 나타나고, 기본 상태에서는 화면에 별만 보입니다. 1을 촘촘히(1.2초 간격 이내) 계속 보내면 같은 주문이 이어지는 것으로 보고 시전 효과를 반복하지 않습니다. 시간 값은 `index.html`의 `SPELL_HOLD_MS`, `SPELL_STREAM_MS`로 바꿀 수 있습니다.

글자 `SPELL` / `STOP` / `NOTHING` 으로 보내도 똑같이 동작합니다. `시리얼 값 쓰기`가 보내는 `x:1` 모양도 인식합니다.

```javascript
// 받는 마이크로비트
radio.setGroup(71)
radio.onReceivedNumber(function (receivedNumber) {
    serial.writeLine("" + receivedNumber)
})
```

왼쪽 메뉴 아래의 **받은 신호 (시리얼 모니터)** 에 마이크로비트가 보낸 글자가 시간과 함께 바로 표시됩니다. 연결 후 12초 동안 아무것도 오지 않으면 확인할 점을 알려 줍니다. `시리얼 문자열 쓰기`처럼 줄바꿈 없이 보내도 인식합니다.

마법이 펼쳐진 상태에서 화면의 다른 원소 버튼을 누르면 그 원소로 바로 바뀝니다. 보드레이트는 MakeCode 기본값 115200입니다.

### 단축키
