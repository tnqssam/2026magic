마이크로비트 연결 방법

받는 마이크로비트(컴퓨터에 USB로 연결): MakeCode에서 라디오 그룹을 71로 정하고, 라디오 문자열을 받았을 때 → 받은 문자열을 시리얼 한 줄 쓰기를 넣으세요.

원소는 이 화면 아래 버튼으로 고르고, 마법봉 마이크로비트는 같은 그룹 71에서 아래 세 가지 문자열만 라디오 문자열 보내기로 보내면 돼요.

SPELL고른 원소 마법 펼치기 (펼쳐져 있으면 다시 시전)
STOP마법 끄기
NOTHING아무 변화 없음 (현재 상태 유지)

Chrome 또는 Edge에서 아래 연결 버튼을 누르고 마이크로비트의 USB 시리얼 포트를 선택하세요. 다른 시리얼 모니터(MakeCode 콘솔 등)는 닫아 두세요.

키보드: 1~5 원소 고르기 · Space 시전(SPELL) · 0/Esc 끄기 · F 전체화면 · H 버튼 숨기기
